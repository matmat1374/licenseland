# راه‌اندازی ترب (Torob) — وضعیت و اقدامات

**تاریخ:** ۲۴ شهریور ۱۴۰۵ · **منبع درخواست:** پیام پشتیبانی ترب (panel.torob.com)

---

## ۱. خواستهٔ ترب

ربات ترب نسخهٔ **بدون جاوااسکریپت** صفحهٔ محصول را می‌خواند و این متاتگ‌ها را لازم دارد:

```
<meta name="product_id"       content="2234">
<meta name="product_name"     content="name">
<meta property="og:image"     content="image_url">
<meta name="product_price"    content="12234">
<meta name="product_old_price" content="12234">
<meta name="availability"     content="instock | outofstock">
<meta name="guarantee"        content="guarantee_sample">
```

و یکی از این دو را برای ساخت ربات فروشگاه:
- لینک صفحه‌ای که **بدون جاوااسکریپت همهٔ محصولات** را به ترتیب جدیدترین نشان دهد، **یا** لینک سایت‌مپ
- **یا** یک API طبق مستندات `https://panel.torob.com/s/docs`

## ۲. وضعیت پیش از اصلاح (اندازه‌گیری‌شده)

| مورد | وضعیت قبلی |
|---|---|
| `product_id` / `product_name` / `product_price` / `availability` در HTML | ❌ وجود نداشت |
| `product_old_price` | ❌ وجود نداشت |
| `guarantee` | ❌ وجود نداشت |
| `og:image` | ❌ وجود نداشت |
| API ترب (`/api/torob`) | ⚠️ موجود بود اما **`isAvailable` همیشه `true`** بود و تصویر/شناسه نداشت |
| robots.txt | ❌ مسیر `/api` را بسته بود → ربات ترب به فید دسترسی نداشت |
| تصویر محصول در دیتابیس | ❌ فقط **۱ از ۱۰۴۹** محصول تصویر داشت |
| سایت‌مپ | ✅ از قبل کار می‌کرد (۷۹۸ آدرس) |

## ۳. اصلاحات انجام‌شده

### الف) ماژول مشترک `src/lib/torob.ts`
یک منبع حقیقت واحد برای متاتگ‌ها **و** فید، تا هرگز با هم اختلاف نداشته باشند:

| تابع | نقش |
|---|---|
| `torobAvailability()` | `instock`/`outofstock` بر اساس موجودی واقعی |
| `torobPrices()` | قیمت فعلی + «قیمت قبل از تخفیف» فقط اگر تخفیف واقعی باشد |
| `torobGuarantee()` | متن گارانتی **فقط اگر واقعاً وجود داشته باشد** |
| `resolveTorobImage()` | عکس محصول → کارت برند → تصویر پیش‌فرض سایت |
| `buildTorobMetaTags()` | تولید متاتگ‌های `<meta name="...">` |
| `buildTorobFeedItem()` | تولید آیتم فید JSON |

**سه قاعدهٔ صداقت که در کد تضمین شده‌اند:**
1. اگر محصول «بدون گارانتی» باشد، تگ `guarantee` **صادر نمی‌شود** (گارانتی جعلی نمی‌سازیم).
2. «قیمت قبل از تخفیف» فقط وقتی نمایش داده می‌شود که تخفیف واقعی باشد.
3. اگر برند ناشناس باشد، تصویر پیش‌فرض سایت می‌آید، نه عکس ساختگی یک محصول دیگر.

### ب) صفحهٔ محصول (بدون جاوااسکریپت)
`generateMetadata` در `src/app/product/[slug]/page.tsx` حالا متاتگ‌های ترب را در `<head>` خروجی HTML سرور می‌گذارد.

### ج) فید `/api/torob`
بازنویسی شد: موجودی واقعی، تصویر مطلق، شناسه، گارانتی، و ترتیب «جدیدترین اول».
دو حالت خروجی دارد: آرایهٔ ساده (سازگار با قبل) و `?format=object` برای `{ products, count }`.

### د) `robots.txt`
مسیر `/api/torob` به فهرست دسترسی ربات اضافه شد تا ترب بتواند فید را بخواند.

### ه) تصویر پیش‌فرض `public/og-default.png`
کارت برند ۱۲۰۰×۶۳۰ برای محصولاتی که عکس ندارند.

## ۵. آنچه باید به ترب ارسال شود

| مورد | آدرس |
|---|---|
| سایت‌مپ فروشگاه | `https://liceno.ir/sitemap.xml` (۷۹۸ آدرس) |
| فید محصولات (API) | `https://liceno.ir/api/torob` |

متن پیشنهادی برای پاسخ:

> سلام، موارد متاتگ در صفحهٔ محصول اضافه شد (product_id, product_name, og:image, product_price, product_old_price, availability, guarantee). لینک سایت‌مپ فروشگاه: `https://liceno.ir/sitemap.xml` و فید محصولات: `https://liceno.ir/api/torob`. لطفاً برای فید، مستندات مربوطه را ارسال کنید تا قالب خروجی (پوشش آرایه/آبجکت) دقیقاً مطابق انتظار تنظیم شود.

## ۶. کار باقی‌مانده (نیازمند تصمیم شما)

1. **تصاویر محصول:** کاتالوگ تقریباً بدون عکس است (۱ از ۱۰۴۹). فیلد تصویر در API تأمین‌کننده تعریف شده (`image` / `imageUrl` / `images[]`) اما مقدار خالی برمی‌گردد. تا زمان تأمین تصاویر واقعی، کارت برند جای آن را می‌گیرد — ترب معمولاً تصاویر عمومی/برندی را ضعیف‌تر می‌پذیرد، پس این مهم‌ترین اقدام برای نتیجهٔ بهتر در ترب است.
2. **تأیید قالب فید:** اگر ترب پوشش `{ products: [...] }` بخواهد، از `?format=object` استفاده کنید؛ در غیر این صورت آرایهٔ ساده پیش‌فرض است.
3. **دیپلوی:** این تغییرات فقط در ریپوی محلی است و روی پروداکشن اعمال نشده.
