# فاز ۰ — ممیزی مبنا (Baseline Audit)

**هدف یک‌خطی:** ثبت وضعیت واقعی ریپوی `matmat1374/licenseland` و شکاف آن با یک فروشگاه لایسنس Production-Grade، بدون نوشتن هیچ فیچر.

## ۰.۱ یادداشت طراحی: چه چیزی را نمی‌دانم و چگونه تایید می‌کنم

| مجهول | روش تایید | نتیجه واقعی |
|---|---|---|
| محتوای کامل `src/` | Git Trees API با `recursive=1` | پاسخ **truncated** برگشت؛ فهرست فایل‌ها **ناقص** است |
| رفتار بیلد و ران‌تایم | clone + `npm ci` + `next build` | **اجرا نشد** — سندباکس شبکه خروجی ندارد (`Could not resolve host: github.com`) |
| Lighthouse / Bundle / Console errors | اجرای واقعی روی بیلد | **اجرا نشد** — همان دلیل |
| محتوای `.env` تراکم‌شده در ریپو | عمداً fetch نشد | تصمیم امنیتی: کلیدها را نمی‌خوانم؛ همه را «افشا‌شده» فرض می‌کنم |
| تاریخچه گیت (Secret Scan) | `git log -p` + gitleaks | **اجرا نشد**؛ اما وجود `.env` در درخت فایل main اثبات‌شده است |

> **قانون صداقت:** هر متریکی که در جدول‌های زیر «اجرا نشد» خورده، ادعای PASS ندارد. علت ریشه‌ای: این محیط اجرا دسترسی شبکه و دسترسی نوشتن به ریپو ندارد.
