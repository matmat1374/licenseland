# ریشه‌یابی — خطای ما در برابر خطای تأمین‌کننده

هر تناقض با **شاهد** (کد یا داده) به یک سمت نسبت داده شده است. نسبت‌دهی بدون شاهد پذیرفته نشده.

## الف) خطاهای سمت ما (فرایند داخلی)

### M1 — نرمال‌ساز عنوان، ویژگی‌های تفکیک‌کننده را حذف می‌کند
**شاهد کد:** `src/lib/supplier.ts` → `localizeProduct()` خط ۶۳۷–۶۴۰

```ts
} else if (/claude/i.test(t) && !/otp|virtual/i.test(t)) {
  if (/team/i.test(t)) finalTitle = "Claude Team";
  else finalTitle = "Claude Pro";     // ← همهٔ انواع Claude به یک نام فروکاسته می‌شود
}
...

  finalTitle = `${finalTitle} (${durationFa})`;   // ← فقط مدت به عنوان اضافه می‌شود
```

سهمیهٔ توکن (۱۰M/۵۰M/۱۰۰M)، سطح (Standard/VIP) و نوع دسترسی (API/Seat/Account) **همه دور ریخته می‌شوند**.
همین الگو برای Midjourney، Canva، Spotify، Netflix، YouTube، Discord، Cursor، Windsurf و Adobe هم وجود دارد.
**اثر:** ۲۳ محصول Claude عنوان «Claude Pro (…)» گرفتند در حالی که کارکردشان کاملاً متفاوت است.

### M2 — کلید یکتایی سینک، شناسهٔ تأمین‌کننده است نه هویت محصول
**شاهد کد:** `scripts/rebuild-catalog.mjs` خط ۵۶۷–۵۷۷

```js

```

هر بار تأمین‌کننده محصول را با **شناسهٔ جدید** فهرست کند (۲۸۱۴ → ۳۲۶۵ → ۳۲۲۸)، هیچ تطبیقی رخ نمی‌دهد و یک **محصول تازه** ساخته می‌شود.
**اثر:** ۱۳۸ گروه تکراری (۳۴۱ محصول) — مثلاً «API Claude Standard 100M Token 1 Day» با شناسه‌های ۲۸۱۴، ۳۲۶۵ و ۳۳۲۸ به‌صورت سه محصول جدا.

### M3 — تطبیق رشتهٔ دقیق، نام‌های معادل را نمی‌گیرد
`"Openai — Brazil"` و `"ChatGPT — Brazil"` یک محصول‌اند ولی رشته‌شان متفاوت است؛ `"YOUTUBE PREMIUM SLOT 6 MONTHS"` و `"Youtube Premium slot official 6 months"` هم.
**اثر:** بخشی از تکراری‌ها در پاس اول (رشتهٔ دقیق) دیده نشدند — با کلید نرمال‌شده پوشش داده شد.

### M4 — شرح کوتاه، متن خام انگلیسی تأمین‌کننده است
`shortDesc` مستقیم از فیلد `name` تأمین‌کننده پر می‌شود: `"API 50M Tokens 1 day full warranty"`.
**اثر:** کاربر فارسی‌زبان تنها منبع تفکیک را نمی‌فهمد؛ صفحهٔ محصول هیچ فیلد ساخت‌یافته‌ای برای سهمیه/نوع ندارد.

### M5 — نبود دروازهٔ کنترل کیفیت پیش از انتشار
هیچ مرحله‌ای پیش از فعال‌شدن محصول، «تکرار عنوان»، «تناقض قیمت» یا «نبود مشخصات» را نمی‌گیرد.
**اثر:** محصولات تکراری با وضعیت فعال و گاهی ۱۰۰ برابر اختلاف قیمت در کنار هم در `/shop` دیده می‌شوند (نمونه: دو «Claude Pro (۱ روزه)» با ۱٬۰۰۱٬۰۰۰ و ۱٬۶۴۷٬۰۰۰ تومان).

### M7 — رشته‌های فارسی با کدگذاری اشتباه (کشف‌شده حین اصلاح)
**شاهد کد:** بخشی از `src/lib/supplier.ts` با Windows-1252 ذخیره شده بود (`"Ø´Ù…Ø§Ø±Ù‡ Ù…Ø¬Ø§Ø²ÛŒ"` به‌جای «شماره مجازی»).
نتیجه: هر عبارت باقاعدهٔ فارسی در این مسیر **هرگز مطابقت نمی‌کند** و هر رشته‌ای که این فایل بسازد، خراب ذخیره می‌شود. دو مورد مستقیماً دربارهٔ عنوان است: تشخیص «شماره مجازی» و برچسب «بدون گارانتی».
**رفع:** ۸۵۳ رشته با بازگردانی cp1252→UTF-8 تعمیر شد؛ صفر کاراکتر خراب باقی ماند و کد دست‌نخورده است (`scripts/fix-mojibake.mjs`).

### M6 — موجودی جعلی ۹۹
`decorate()` برای محصولات AUTO مقدار `Math.max(stock, 99)` برمی‌گرداند.
**اثر:** حس فوریت و اعتماد از بین می‌رود و «موجودی» معنای خود را از دست می‌دهد.

## ب) خطاهای سمت تأمین‌کننده (irMarket)

### S1 — فهرست‌گذاری مجدد با شناسهٔ جدید
هر بار محصول با شناسهٔ تازه ثبت می‌شود (شاهد: `supplier_product_id` متفاوت با همان نام و همان سهمیه).
**اثر:** موتور سینک را به ساخت محصول جدید می‌کشاند (M2 را فعال می‌کند).

### S2 — نام‌گذاری فنی و ناقص
نام‌ها انگلیسی و تلگرافی‌اند: `"Claude API 50$ Token 1 month 30 days warranty"`, `"Claude Premium Seat 1 Month"`, `"CLAUDE PRO 7 DAYS (warranty 5 DAYS)"`.
هیچ فیلد ساخت‌یافته‌ای برای سهمیه/سطح/نوع دسترسی وجود ندارد.

### S3 — نام یکسان برای محصولات متفاوت
نام «Claude Pro» هم برای **کردیت API**، هم **صندلی پریمیوم** و هم **اکانت تریال** استفاده می‌شود.

### S4 — تغییر قیمت بدون اطلاع
همان محصول در فهرست‌های مختلف قیمت دلاری متفاوتی دارد (۵٫۶۹ / ۵٫۰۲ / ۵٫۰۲ دلار) و بدون اعلام تغییر می‌کند.

### S5 — ابهام گارانتی
ترکیب «۱ ماهه» با «warranty 24H» یا «warranty 5 DAYS» در یک نام، تفسیر مدت و گارانتی را مبهم می‌کند.
