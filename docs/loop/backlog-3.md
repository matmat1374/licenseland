## راستی‌آزمایی مستقل

یک عامل جداگانه با دستور «تأیید نکن، **رد کن**» هر دو اصلاح را آزمود (گزارش کامل: `docs/loop/verify-3.md`). نتیجه: **هر دو APPROVE** و یک `ESCALATE_HUMAN` روی نیمهٔ تجاری تصمیم `?cat=` (خارج‌شدن ۱۰ دستهٔ پرمحصول از ایندکس = تصمیم راهبردی مالک).

- مقدارِ افزودهٔ راستی‌آزما: **سایت‌مپ تولید از نظر XML well-formed نبود** (۳ آدرس با `&` خام، ۱۱ با فاصلهٔ خام) — که تصمیم «سایت‌مپ اشتباه بود» را قطعی‌تر می‌کند.

- دو ویرایش آرایشی **بعد از** راستی‌آزمایی انجام شد (حذف import بی‌استفادهٔ `Folder`، تصحیح عدد کامنت). اثبات بی‌اثر بودنشان: هر ۴۱ چانک خروجی **بیت‌یکسان** (۰ حذف، ۰ افزودن، ۰ تغییر اندازه/hash) ⇒ همهٔ اعداد و بررسی‌ها برای درخت نهایی معتبر می‌مانند.
